# 持续优化：第二轮实测与产品调整

状态：持续推进中的阶段记录，不是“全面优化完成”。第一轮基线为 `2db4ea9`。

## 产品判断与已实施取舍

网站的核心应是帮助文博学习者和从业者完成三件事：知道发生了什么且能核对、找到可以采取行动的机会、持续跟进一个方向。按日报文件日期组织所有入口，不足以完成后两件事。

| 模块 | 角色与取舍 | 本轮落地 |
| --- | --- | --- |
| 首页 | 从刊物入口转向近期内容入口；不追求固定条数填满日报 | 增加近期内容流、主题筛选、分别列出来源日期与收录日期 |
| 日报 | 保留完整编辑上下文和历史版本，不与首页另建采集流程 | 条目级纠错、来源依据、收藏；原始 Markdown 保留 |
| 招聘 / 实习 | 同属“机会”，但就业、实习、志愿服务不是同类权益 | 合并全站入口，保留分视图；筛选先于长说明，志愿服务明确命名 |
| 搜索 | 找到具体信息后能直接行动 | 完整关键词匹配、内容类型筛选、逐岗位索引和锚点、每批30条 |
| 行业观察 | 概览引导到证据；地图和数字趋势是不同样本 | 修复暗色对比度；统一正式巡检口径；保留专门分析页作为详情 |
| 周报 / 月报 | 提供时间跨度更长的编辑判断，作为档案中的阅读层 | 保留；不因为有同主题报道就自动删掉有时间上下文的刊期 |
| 回访 | 让用户能找回读到一半的报道或准备申请的岗位 | 本浏览器收藏、主题筛选链接、现有 RSS；没有账号和付费服务依赖 |
| 重复控件 | 只有帮助当前任务才应保留 | 删除招聘重复统计块和冗余全站入口；长收录说明折叠 |

机会页当前仍有大量“状态待核验”条目。这是可用性瓶颈，不能靠把“长期招募”自动标绿解决。后续应建立逐条最后核验日期、申请资格和有效期限证据，而非仅增加聚合数量。

## 数据模型边界

- 来源文档：原始 URL、来源名称、原文日期；一份汇编可以包含多个事件。
- 事件：使用编辑账本已经明确的事件 ID；没有可靠映射时保持条目独立，不凭共用 URL 合并。
- 进展 / 收录：保留每次日报日期、原文、条目锚点和新进展标记。`reader-events.json` 是既有编辑数据的派生视图，不是第二套生产账本。
- 抓取聚类：代表报道日期与 `firstReportedDate`、`latestReportedDate` 分离。优先保留已识别的新进展；不把最近转载时间冒充代表原文日期。
- 岗位：机构、岗位、原公告、报名窗口及申请方式；页面和搜索使用同一稳定锚点。
- 纠错：独立的条目级证据覆盖层，绑定日期、条目 ID 和标题；原稿标题变化后构建会要求重新核对映射，避免更正贴错文章。

目前没有把历史每个条目都硬映射为事件。既有事件 ID 仍由历史启发式产生，不能把派生视图当作已经完成的实体数据库。不同事件共用汇编链接、不同政策同名词、英文动词子串误判已有保护；跨语言实体消歧与多阶段事件仍需更大标注集。

## 实测数据与局限

`audit/live-discovery-2026-09-06.json` 是独立质量审计，窗口8月31日至9月6日。没有写入或冒充早7:13的生产运行。

- 142次搜索请求中126次成功；16次超时。1162条原始发现记录。
- 8个直接来源扫描均发生运行环境DNS解析失败。该结果说明本环境的直连扫描未完成，不说明这些网站没有更新。
- 搜索请求成功不等于召回完整，1162条也不等于1162条合格文博新闻。不能用这些数字宣称覆盖率提升。
- 11对人工检查的困难样本（8负例、3正例），旧逻辑4对正确、有7次误合并；本轮11对正确，无漏配。样本是针对已发现错误选取的挑战集，不是全网精确率/召回率。
- 政策冲突例：深圳非国有博物馆扶持办法、考古文物移交办法、博物馆藏品办法曾混入同组。
- 英文词形例：closer曾触发close，从而把不相关报道混合。
- `audit/dedup-replay-summary.json` 保存当前代码的离线回放；聚类数量变化本身不代表质量改善。

固定国内来源原有直连规则保留，没有改写代理或使用新的外部服务来绕过访问限制。仍需在原有可直连的运行环境验证8个来源扫描，并测量失败恢复和连续多日覆盖。

## 历史原文核查

`content/复核/history-source-audit.json` 包含15条核查记录。覆盖第一轮六组共用URL告警，并延伸检查了关联旧政策。

- 极目新闻的北京研讨会报道被用于三星堆结论；光明日报的北京中轴线报道被用于花山岩画。均按具体引用错配标注，不把其他尚未核对的来源一并判假。
- 7月29日世界遗产新增数量有原文支持；釜山宣言、第六战略目标的具体表述未在该原文找到。
- 财新是一页多新闻汇编，目录对应事件；本轮未核到相应全文细节，标为部分核验。
- 国家文物资源数据办法解读官方转载日期7月6日；地下文物埋藏区指南解读2月28日；预防性保护技术导则问答2025年10月21日。不能只因为晚些被日报收录就称新发布。
- AP共同引用原文仍不可读取，保留未解决状态，不用访问失败推断虚假。

本轮不是全部历史正文逐句核验。缺失证据仍须继续补全，来源分级也不等于内容已被逐句证实。

## 下一阶段的验收目标

1. 在原有可直连环境补齐来源覆盖实测，尤其招聘官网和公告更新；对失败记录保留明确状态。

3. 优先补全仍在首页、推荐、申请路径上的事实和有效性证据；历史错引继续使用可追溯更正。

5. 真机Safari/Android及受限网络性能、长期任务运行稳定性、生产部署仍未验收。本地提交不代表线上已更新。
