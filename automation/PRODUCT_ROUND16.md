# 第十六轮：整期浏览与日报阅读布局

用户在本地预览后认为上一轮变化不明显。代码核对表明此前以共享样式和筛选细节为主，首页依旧只呈现三条标题；不能把这个结果归因于用户代理波动。

## 本轮交付

- 首页按原有编辑顺序展示最新一期全部新闻，第一条为主卡，其余为新闻卡。显示正文摘录、来源名称与直达对应日报条目的链接，不引入新的摘要生成或排序。
- 当前最新一期 7 条，首页 7 张卡；近两周筛选与六条分页保留。
- 日报正文用独立 article 分隔；宽屏左侧目录、右侧正文，900px 以下单栏，600px 以下目录单栏。锚点保持稳定，历史日报同样重新生成。
- 用户明确配色：浅色以黑白灰为主，深色使用深蓝；蓝色用于链接、选中状态和焦点；琥珀色/红色用于真实异常。取消墨绿、奶黄色主背景；主题标签统一中性底色。
- CSS 文件 URL 带内容哈希，已经装饰过的历史预览页也刷新引用，避免长期读旧缓存。
- 招聘数据与业务逻辑未改；只同步共享样式版本。

## 跨页面阅读路径

- 搜索结果改为直接可读的文章列表，日期、摘要、来源不再藏在展开按钮里；标题直接打开对应正文。
- 增加收录起止日期、最新/匹配度排序。空关键词可浏览，日期倒置有明确恢复提示，非法参数回到默认值。这里筛选的是期刊收录日期，不伪装成事件发生日期。
- 档案默认显示最近七期日报；按期号月份筛选时自动显示折叠组中的对应记录，清除后恢复初始折叠，URL 可保存月份。
- 收藏加入全站导航，历史预览页的导航也同步更新。

## 验证边界

270 项自动化测试全部通过；构建、项目校验、84 页产品校验通过；8 个本地 HTTP 页面/资源返回 200；最新一期首页卡片与日报条目、目标锚点及全站 CSS 版本核对。见 audit/round16-layout-validation.json。
云端浏览器安全策略此前拒绝本地页面访问，未绕过限制，没有新版真实浏览器截图，不声称视觉验收完成。本地必须看 390px 手机、1440px 桌面和浅/深色两种模式后再确认上线。

## 后续判断

先确认用户认可页面外观，再回到信息供给：区分事件发生日期与报道日期，避免旧事件被新报道重新包装；以早间真实运行的国内外覆盖、事件级去重和最终精选数量衡量改善，目标 6–9 条，不按数量凑稿。
